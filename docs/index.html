Multi-Tenant RAG Retrieval Service

A Python-based AI engineering project demonstrating vector search, retrieval, embeddings, semantic caching and multi-tenant knowledge-base isolation.

Project Features

  • Python and FastAPI REST interface
  • Qdrant vector database
  • Hugging Face Sentence Transformers
  • BGE-small text embeddings
  • Tenant-filtered vector retrieval
  • Cosine similarity search
  • Semantic caching with TTL
  • Session and tenant cache separation
  • Illustrative PII redaction
  • Heuristic prompt-injection checks
  • Bearer-token API authentication
  • Rate limiting and request metrics
  • Python and Jupyter Notebook demos
  • CPU and optional CUDA support

System Architecture

Client request, tenant authentication, input checks, semantic cache, BGE embeddings, Qdrant vector retrieval, and extractive knowledge-base results.

Retrieval and Embeddings

The service uses BAAI/bge-small-en-v1.5 embeddings and Qdrant payload filters to retrieve relevant tenant-specific knowledge-base passages.

Project Scope

This is an educational retrieval demo. It returns excerpts rather than LLM-generated answers. The security controls are illustrative and have not undergone production security review.
